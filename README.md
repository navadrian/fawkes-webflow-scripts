# fawkes-webflow-scripts

Hosted custom scripts + CSS for the Fawkes Energy Webflow site, loaded via jsDelivr and registered as hosted scripts in Webflow.

| File | Purpose |
|---|---|
| `fk-contrast.css` | text-contrast overrides + fixed-nav anchor/heading offset (P0-4) |
| `fk-mobilenav.css` | mobile (<768px) nav styling |
| `fk-site-interactions.js` | hamburger toggle, mobile dropdowns, Home industries tab switcher, empty-slot hiding |
| `fk-hero-sticky.css` | sticky hero freeze/release positioning + base scrim |
| `heropinsimple.js` | one scrubbed GSAP ScrollTrigger per hero (scrim darken + content fade + subtle scale) |

Load pattern: `https://cdn.jsdelivr.net/gh/navadrian/fawkes-webflow-scripts@<tag>/<file>`
